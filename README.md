# AI-MatSci-Lab-ADI

> A repository containing Artificial Intelligence and Materials Science laboratory experiments, Python implementations, datasets, and Jupyter notebooks for learning data analysis, machine learning, and materials informatics.

---

## 📖 Overview

AI-MatSci-Lab-ADI is a collection of laboratory exercises developed to understand the application of **Artificial Intelligence (AI)** and **Python programming** in **Materials Science**. The repository includes datasets, data preprocessing, visualization, filtering, machine learning basics, and practical implementations using Jupyter Notebook.

This repository is intended for:
- Engineering Students
- Materials Science Enthusiasts
- AI Beginners
- Python Learners
- Academic Laboratory Work

---

## 🚀 Features

- Python-based laboratory experiments
- Materials dataset creation and manipulation
- Data preprocessing using Pandas
- Data visualization with Matplotlib
- Filtering and sorting datasets
- Unit conversion examples
- Basic Machine Learning concepts
- Jupyter Notebook implementations
- Well-commented source code

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/adityay82/AI-MatSci-Lab-ADI.git
```

Navigate into the project

```bash
cd AI-MatSci-Lab-ADI
```

Install required libraries

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook

```bash
jupyter notebook
```
